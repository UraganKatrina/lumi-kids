# Публикация в Google Play и App Store

Чек-лист перед первой отправкой. Галочки ставит человек, который сделал шаг.
Пока ни один шаг в магазинах не выполнен, и соответствие правилам магазинов
не подтверждено: это решают проверки Google и Apple.

## 1. Решить до первой загрузки (потом не поменять)

- [ ] Идентификатор приложения. Сейчас `com.lumikids.lumi_kids` (Android) и
      `com.lumikids.lumiKids` (iOS). После первой публикации сменить нельзя.
      Если нужен другой, поменять в `android/app/build.gradle.kts`,
      `lib/core/external_links.dart` и в Xcode.
- [ ] Аккаунт разработчика: частное лицо или компания. От этого зависит имя
      продавца в магазине и налоговые формы (см. `docs/subscriptions.md`).

## 2. Документы

- [ ] Юрист проверил `docs/legal/privacy-policy.*.md` и `docs/legal/terms.*.md`,
      поля в скобках заполнены, есть узбекская версия.
- [ ] Документы опубликованы по постоянным адресам (например, GitHub Pages
      или сайт). Адреса передаются при сборке:
      `--dart-define=LUMI_PRIVACY_URL=... --dart-define=LUMI_TERMS_URL=...`.
      Без них ссылок в приложении нет, и Apple отклонит экран подписки.

## 3. Сервер

- [ ] API развёрнут по HTTPS, `MIGRATE_ON_START` или миграции выполнены.
- [ ] Настроены ключи Google и Apple для проверки покупок
      (`services/api/README.md`), за прокси задан `TRUST_PROXY`.
- [ ] Выпущен пакет заданий, прошедших проверку методиста.

## 4. Сборка

- Android, подпись. Создать ключ загрузки один раз и хранить вне репозитория
  (потеря ключа = нельзя обновлять приложение, если не включена Play App
  Signing):
  ```
  keytool -genkey -v -keystore ~/lumi-upload.jks -keyalg RSA -keysize 2048 \
    -validity 10000 -alias upload
  ```
  Файл `apps/mobile/android/key.properties` (в `.gitignore`):
  ```
  storeFile=/полный/путь/lumi-upload.jks
  storePassword=...
  keyAlias=upload
  keyPassword=...
  ```
- Android, сборка для Google Play:
  ```
  flutter build appbundle --release \
    --dart-define=LUMI_API_URL=https://... \
    --dart-define=LUMI_PRIVACY_URL=https://... \
    --dart-define=LUMI_TERMS_URL=https://...
  ```
  Без `key.properties` сборка подписывается отладочным ключом: так CI
  проверяет, что release собирается, но в магазин такой файл не загрузить.
- iOS собирается только на Mac с Xcode: `flutter build ipa` с теми же
  `--dart-define`. В Xcode выбрать команду разработчика (Signing & Capabilities)
  и добавить возможность In-App Purchase. Здесь iOS-сборка не проверялась.
- [ ] Иконка и экран запуска: сейчас стандартные иконки Flutter, нужны свои.

## 5. Google Play Console

- [ ] Целевая аудитория: до 5 лет и 6–8 лет. Приложение попадает в программу
      Families: обязательны правила для детских приложений.
- [ ] Реклама: «Нет рекламы». Рекламный идентификатор убран из сборки
      (`AD_ID` с `tools:node="remove"` в манифесте, проверяется тестом).
- [ ] Возрастной рейтинг IARC: анкета без насилия, покупок без контроля
      родителя, общения между пользователями.
- [ ] Data safety (ответы подтвердить юристом):
  - данные, которые хранятся только на устройстве, в форму не входят;
  - «Финансовая информация → История покупок»: собирается, не передаётся
    третьим лицам, обрабатывается кратковременно (сервер не сохраняет),
    обязательна, цель: работа приложения;
  - шифрование при передаче: да (HTTPS);
  - удаление данных: в приложении, кнопка «Удалить все данные».
- [ ] Подписки `lumi_premium_monthly` и `lumi_premium_yearly` созданы, цены
      заданы, тестировщики лицензий добавлены, покупка проверена на
      устройстве из закрытого тестирования.
- [ ] Скриншоты телефона и планшета, короткое и полное описание на ru/uz/en.

## 6. App Store Connect

- [ ] Категория Kids, возрастные группы «5 лет и младше» и «6–8 лет».
      Правила: никакой сторонней рекламы и аналитики, покупки и внешние
      ссылки только за родительским барьером (в приложении это так).
- [ ] App Privacy: «Покупки», не связаны с личностью, не для отслеживания,
      цель: функциональность. Отслеживания нет (ATT не нужен).
- [ ] Privacy manifest: Flutter и плагины поставляют свои; проверить отчёт
      Xcode при архивации (Product → Archive → Generate Privacy Report).
- [ ] Подписки в одной группе, локализованные названия, скриншот экрана
      подписки для проверки, Sandbox-покупка проверена.
- [ ] Экспортное шифрование: в `Info.plist` указано
      `ITSAppUsesNonExemptEncryption = false` (только HTTPS).

## 7. Проверено автоматически (CI)

- форматирование, анализатор, тесты приложения, включая тесты доступности:
  кнопки не меньше 48×48, у каждой кнопки есть подпись для диктора,
  контраст текста, крупный шрифт на трёх языках без обрезанных строк;
- release-сборка Android (подписанная отладочным ключом);
- тесты сервера и админки.

## 8. Проверить вручную на устройствах

- [ ] TalkBack (Android) и VoiceOver (iOS) на карте, задании и кабинете.
- [ ] Маленький телефон и планшет, книжная и альбомная ориентация.
- [ ] Без интернета: первый запуск, задания, кабинет.
- [ ] Покупка, отмена, восстановление, истечение подписки (в Sandbox
      подписки истекают за минуты).
- [ ] Узбекский и английский тексты вычитаны носителями.
