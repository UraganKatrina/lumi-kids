# Модели данных LUMI Kids

Здесь описаны основные сущности. Задание (`Task`) описано строго в
[content/schema/task.schema.json](../content/schema/task.schema.json);
эталонные примеры лежат в [content/examples/](../content/examples/).

## 1. Справочники

### Направления развития (`DevelopmentArea`)

| Код | Название |
|---|---|
| `speech` | Речь и коммуникация |
| `logic` | Логика и мышление |
| `math` | Математика и числа |
| `literacy` | Чтение, буквы и подготовка к письму |
| `memory_attention` | Память и внимание |
| `emotional_social` | Эмоциональный интеллект и социальные навыки |
| `self_care` | Самостоятельность и бытовые навыки |
| `creativity` | Творчество, рисование и воображение |
| `world` | Окружающий мир, природа, животные и наука |
| `music` | Музыка, ритм и слуховое восприятие |
| `movement` | Движение, координация и крупная моторика |
| `languages` | Иностранные языки |

### Возрастные программы (`AgeProgram`)

Возраст хранится в месяцах: так проще сравнивать и не нужна дата рождения целиком.

| Код | Месяцы | Особенность |
|---|---|---|
| `infant` | 0–11 | только совместно со взрослым (`withParent: true`) |
| `toddler` | 12–23 | |
| `early` | 24–35 | |
| `preschool` | 36–59 | |
| `school_prep` | 60–84 | |

Возраст задаёт стартовый уровень, а дальше сложность подстраивается по
результатам (см. «Прогресс»).

### Типы упражнений (`ExerciseType`)

`choice`, `match_pairs`, `drag_drop`, `sort`, `classify`, `sequence`,
`spot_difference`, `memory`, `sound_recognition`, `audio_instruction`,
`math_simple`, `tracing`, `story`, `creative`.

Для первых типов (`choice`, `match_pairs`, `sort`, `classify`, `sequence`)
содержимое задания описано в схеме строго. Остальные типы получат строгое
описание, когда для них появится движок.

## 2. Контент

### Задание (`Task`)

| Поле | Смысл |
|---|---|
| `id` | постоянный идентификатор, например `math.count.apples.001` |
| `schemaVersion` | версия формата |
| `version` | версия этого задания, растёт при каждой правке |
| `minAppVersion` | минимальная версия приложения, которая умеет его показать |
| `area` | направление развития |
| `goalId` | образовательная цель (ссылка на справочник целей) |
| `skills` | навыки, на которые влияет задание |
| `ageRange` | `minMonths`–`maxMonths` |
| `difficulty` | 1–5 |
| `withParent` | задание выполняется вместе со взрослым |
| `exerciseType` | тип упражнения |
| `instruction` | текст на ru / uz / en и аудио-инструкция |
| `content` | данные упражнения: варианты, пары, группы, порядок |
| `hints` | подсказки по нарастающей |
| `media` | все используемые файлы с хэшами для офлайн-проверки |
| `reward` | что даётся за выполнение (декоративные предметы, без случайных призов) |
| `review` | статус проверки: `draft` → `in_review` → `approved` → `published` / `withdrawn` |
| `rights` | источник и лицензия каждого материала |

Правило публикации: в пакет попадают только задания со статусом
`published`, у которых есть тексты на всех языках пакета и заполнены права
на все медиа.

### Пакет контента (`ContentPack`)

`id`, `packVersion`, `schemaVersion`, `languages`, `tasks[]`,
`media[]` (путь, размер, sha256), `publishedAt`. Приложение скачивает пакет
целиком, проверяет хэши и только потом показывает задания.

### Образовательная цель (`LearningGoal`)

`id`, `area`, `title` (ru / uz / en), `ageRange`, `description`
для родителя. Цели формулируются как наблюдаемые действия
(«находит одинаковые предметы»), без диагнозов и сравнений с нормой.

## 3. Пользователи

### Родительский аккаунт (`ParentAccount`) — на сервере

`id`, `email` (для входа и восстановления), `createdAt`, `locale`,
`country` (для правил магазина и налогов), `deletedAt`.
Пароль не хранится в открытом виде; вход через почту или Apple/Google.

### Детский профиль (`ChildProfile`)

`id`, `parentId`, `displayName` (прозвище), `birthMonth` (год и месяц),
`language`, `interests[]`, `areas[]`, `avatarId` (из встроенного набора).
Не храним: фамилию, фото, голос, школу, точную дату рождения.

## 4. Прогресс

### Попытка (`Attempt`) — на устройстве, потом синхронизируется

`id` (UUID с устройства — защищает от дублей при синхронизации),
`childId`, `taskId`, `taskVersion`, `startedAt`, `finishedAt`,
`result` (`success` / `partial` / `skipped`), `hintsUsed`, `mistakes`.

### Навык (`SkillProgress`)

`childId`, `skillId`, `level` (1–5), `confidence`, `lastPracticedAt`.
Уровень меняется постепенно по последним попыткам. Родителю показывается
как «чаще справляется / пока пробует», без оценок «отстаёт».

### Награда (`RewardItem`, `ChildReward`)

Коллекция декоративных предметов. Нет серий входов с потерями, нет
случайных призов за деньги.

## 5. Покупки (этап 8)

`Entitlement`: `parentId`, `product` (`family_monthly`, `family_yearly`,
`lifetime`, `collection:<id>`), `source` (`google_play` / `app_store`),
`status`, `expiresAt`, `originalTransactionId` (уникальный — защита от
повторной обработки). Проверка покупки — только на сервере.
