# План тестирования LUMI Kids

Каждая проверка из этого плана запускается автоматически в GitHub Actions.
Изменение не попадает в `main`, пока проверки не зелёные.

## 1. Что уже работает

| Проверка | Где | Команда |
|---|---|---|
| Форматирование Dart | `.github/workflows/ci.yml` | `dart format --set-exit-if-changed lib test` |
| Статический анализ | `.github/workflows/ci.yml` | `flutter analyze` |
| Тесты виджетов | `.github/workflows/ci.yml` | `flutter test` |
| Сборка Android (отладочная) | `.github/workflows/ci.yml` | `flutter build apk --debug` |
| Схема и ссылки в заданиях | `.github/workflows/content.yml` | `npm run validate`, `npm test` в `content/` |

## 2. Уровни тестов

| Уровень | Что проверяет | Инструмент | Когда появляется |
|---|---|---|---|
| Модульные | доменные правила: проверка ответа, расчёт уровня навыка, рекомендации, награды | `flutter test` | этап 3 |
| Виджетов | экраны и компоненты: крупные кнопки, состояния загрузки и ошибок | `flutter test` | этап 3 |
| Интеграционные | путь ребёнка «карта → задание → ответ → результат → прогресс сохранён» | `integration_test` на эмуляторе в CI | этап 3 |
| Контент | каждое задание в пакетах проходит схему и правила публикации | `content/` | уже есть |
| Совместимость контента | старые пакеты открываются новой версией приложения; задания новее приложения скрываются | `flutter test` на зафиксированных пакетах | этап 4 |
| Миграции БД | обновление базы на устройстве с каждой прошлой версии | `drift` + тесты миграций | этап 4 |
| Локализация | во всех языках есть все ключи; длинные строки не ломают экран | тест ARB + скриншот-тесты | этап 7 |
| Офлайн | приложение без сети: каталог, задания, прогресс; синхронизация после появления сети без дублей | интеграционные тесты с отключённой сетью | этап 7 |
| Родительский барьер | покупки, ссылки и настройки недоступны без прохождения барьера | тесты виджетов | этап 5 |
| API | контракты, авторизация, доступ только к своим детям, ограничение частоты | Jest + Supertest, тестовая PostgreSQL в CI | этап 6 |
| Покупки | покупка, восстановление, продление, истечение, возврат, повторное уведомление | тесты сервера с записанными ответами магазинов + тестовые аккаунты магазинов | этап 8 |
| Безопасность | секреты не в коде, зависимости без известных уязвимостей | сканирование секретов и зависимостей в CI | этап 6 |

## 3. Ручные проверки перед релизом

- Прохождение основных сценариев на телефоне и планшете Android и на iPhone / iPad.
- Проверка доступности: крупный шрифт системы, озвучивание экрана.
- Проверка с ребёнком целевого возраста под присмотром родителя,
  без сбора записей.

## 4. Критерии готовности этапа

1. Все проверки CI зелёные.
2. Новый код покрыт тестами своего уровня.
3. Результат запускается по инструкции из README.
