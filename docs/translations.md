# Переводы

## Интерфейс приложения

Строки лежат в `apps/mobile/lib/l10n/app_<язык>.arb`:

| Файл | Язык | Состояние |
|---|---|---|
| `app_ru.arb` | русский | основной, шаблон для остальных |
| `app_uz.arb` | узбекский (латиница) | черновой перевод, **нужна проверка носителем** |
| `app_en.arb` | английский | черновой перевод, нужна вычитка |

Правила:

- Добавляя строку, добавьте её во все три файла: тест `test/l10n_test.dart`
  не пропустит разный набор ключей или пустые строки.
- Параметры (`{name}`, `{count}`) описываются только в `app_ru.arb`.
- Для родителя — наблюдения, а не оценки: не «отстаёт», а «пока пробует».
- После правки ARB код в `lib/l10n/generated/` обновится сам при
  `flutter pub get`, `flutter run` или вручную командой `flutter gen-l10n`.

## Тексты заданий

Каждое задание хранит тексты по языкам (`ru` обязателен, `uz` и `en` по
возможности). Приложение показывает текст на выбранном языке, а если
перевода нет — на русском. Пакет на сервере можно выпустить с требованием
нескольких языков: тогда задание без перевода в пакет не попадёт.
