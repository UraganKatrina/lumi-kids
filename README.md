# LUMI Kids

Образовательное приложение для детей 0–7 лет (Flutter, Android и iOS).

## Состояние

Этап 4: возрастные маршруты и движок заданий.

- Взрослый выбирает возраст (0–1, 1–2, 2–3, 3–5, 5–7 лет); карта показывает
  подходящие задания, для малышей до года — только занятия вместе со взрослым.
- Типы упражнений: выбор ответа, последовательность, пары, сортировка,
  классификация, занятие со взрослым.
- «Следующее занятие» подбирается по возрасту и успехам: сложность растёт
  после освоения предыдущего уровня, направления чередуются.
- Стартовый пакет: 37 заданий (черновики, нужна проверка методиста).
- Прогресс и настройки хранятся на устройстве в SQLite, с миграцией базы.

## Структура

- `apps/mobile/` — Flutter-приложение
- `content/` — схема заданий и проверка контента
- `docs/` — [архитектура](docs/architecture.md), [модели данных](docs/data-model.md),
  [план тестирования](docs/testing-plan.md)

## Проверка приложения

```bash
cd apps/mobile
flutter pub get
flutter analyze
flutter test
flutter run            # на подключённом телефоне или эмуляторе
```

После изменения таблиц в `lib/features/progress/data/progress_database.dart`
перегенерируйте код: `dart run build_runner build`.

## Автосборка

При каждом изменении GitHub Actions проверяет форматирование, запускает
`flutter analyze` и `flutter test` и собирает отладочный APK для Android.
Скачать APK: вкладка **Actions** → последний зелёный запуск → раздел
**Artifacts** → `lumi-kids-debug-apk`.
