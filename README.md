# LUMI Kids

Образовательное приложение для детей 0–7 лет (Flutter, Android и iOS).

## Состояние

Этап 5: профили детей и кабинет родителя.

- При первом запуске взрослый создаёт профиль: прозвище, значок, год и месяц
  рождения. Возрастная программа (0–1, 1–2, 2–3, 3–5, 5–7 лет) считается
  по возрасту сама и меняется, когда ребёнок подрастает.
- Можно добавить нескольких детей; у каждого свой прогресс. Переключение
  «Кто играет?» — с карты.
- Раздел «Для взрослых» закрыт родительским барьером (умножение, записанное
  словами). Там: профили, прогресс по направлениям в виде наблюдений,
  история занятий, идеи занятий вместе, удаление профиля и всех данных.
- Типы упражнений: выбор ответа, последовательность, пары, сортировка,
  классификация, занятие со взрослым. «Следующее занятие» подбирается по
  возрасту и успехам.
- Стартовый пакет: 37 заданий (черновики, нужна проверка методиста).
- Все данные хранятся только на устройстве в SQLite. При обновлении с версии
  0.2 прогресс переходит к первому созданному профилю.

## Структура

- `apps/mobile/` — Flutter-приложение
- `content/` — схема заданий и проверка контента
- `docs/` — [архитектура](docs/architecture.md), [модели данных](docs/data-model.md),
  [план тестирования](docs/testing-plan.md)

## Проверка приложения

```bash
cd apps/mobile
flutter pub get
flutter analyze
flutter test
flutter run            # на подключённом телефоне или эмуляторе
```

После изменения таблиц в `lib/features/progress/data/progress_database.dart`
перегенерируйте код: `dart run build_runner build`.

## Автосборка

При каждом изменении GitHub Actions проверяет форматирование, запускает
`flutter analyze` и `flutter test` и собирает отладочный APK для Android.
Скачать APK: вкладка **Actions** → последний зелёный запуск → раздел
**Artifacts** → `lumi-kids-debug-apk`.
