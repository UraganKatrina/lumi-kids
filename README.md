# LUMI Kids

Образовательное приложение для детей 0–7 лет (Flutter, Android и iOS).

## Состояние

Этап 6: сервер и админка для заданий.

- **Приложение** (`apps/mobile`): профили детей, возрастные программы, шесть
  типов упражнений, кабинет родителя за родительским барьером. Данные детей
  хранятся только на телефоне.
- **Языки**: интерфейс на русском, узбекском и английском (по языку телефона
  или по выбору родителя). Тексты заданий показываются на выбранном языке,
  если перевод есть, иначе на русском. Узбекский и английский переводы
  интерфейса сделаны без носителя языка и требуют проверки, см.
  [docs/translations.md](docs/translations.md).
- **Подписка**: без подписки в каждом направлении каждого возраста открыты
  первые три задания, с подпиской все. Оформить её можно только в кабинете
  родителя; ребёнок видит у закрытого задания замок и просьбу позвать
  взрослого. Покупка открывается только после проверки на нашем сервере, см.
  [docs/subscriptions.md](docs/subscriptions.md).
- **Публикация**: чек-лист для Google Play и App Store в
  [docs/store-release.md](docs/store-release.md), черновики политики
  конфиденциальности и условий в [docs/legal](docs/legal) (нужна проверка
  юристом).
- **Сервер** (`services/api`, NestJS + PostgreSQL): задания с историей версий,
  проверка методистом (одобряет только второй человек), выпуск неизменяемых
  пакетов контента с хэшем, журнал действий.
- **Админка** (`apps/admin`, Next.js): вход сотрудников, список и редактор
  заданий с проверкой по схеме, кнопки проверки, выпуск пакетов.
- Стартовый пакет в приложении: 37 заданий (черновики, нужна проверка
  методиста). Их можно загрузить в админку командой `npm run import-tasks`.
- Приложение само проверяет новый пакет заданий на сервере, сверяет хэш и
  включает его со следующего запуска. Без сети работает на скачанном или
  встроенном пакете. Адрес сервера задаётся при сборке:
  `flutter build apk --dart-define=LUMI_API_URL=https://...`.

## Структура

- `apps/mobile/` — Flutter-приложение
- `apps/admin/` — админка редакции ([README](apps/admin/README.md))
- `services/api/` — сервер ([README](services/api/README.md))
- `content/` — схема заданий и проверка контента
- `docs/` — [архитектура](docs/architecture.md), [модели данных](docs/data-model.md),
  [план тестирования](docs/testing-plan.md)

## Проверка приложения

```bash
cd apps/mobile
flutter pub get
flutter analyze
flutter test
flutter run            # на подключённом телефоне или эмуляторе
```

После изменения таблиц в `lib/features/progress/data/progress_database.dart`
перегенерируйте код: `dart run build_runner build`.

## Автосборка

При каждом изменении GitHub Actions проверяет форматирование, запускает
`flutter analyze` и `flutter test` и собирает отладочный APK для Android.
Скачать APK: вкладка **Actions** → последний зелёный запуск → раздел
**Artifacts** → `lumi-kids-debug-apk`.
