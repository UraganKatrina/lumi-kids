# Контент LUMI Kids

- `schema/task.schema.json` — формат одного задания (JSON Schema 2020-12).
- `src/validate.mjs` — проверка задания: схема плюс ссылки между полями
  (правильный ответ есть среди вариантов, у каждого медиафайла указаны права,
  возраст указан корректно и т.д.).
- `examples/` — эталонные задания. Медиафайлы и хэши в них условные,
  переводы на узбекский и английский должен проверить носитель языка.
- `invalid/` — намеренно ошибочные задания; тесты проверяют, что они отклоняются.

```bash
cd content
npm ci
npm run validate   # проверить examples/
npm test           # эталонные проходят, ошибочные отклоняются
node src/cli.mjs <папка>   # проверить любую папку с заданиями
```
